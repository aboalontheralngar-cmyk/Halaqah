# P1.24 install note

This source package is intended to be applied over the existing local P1.23/build68 project directory.

## Font assets

Font binary files are intentionally not included in the transfer archive. Keep the font assets already present in your local project, especially:

- `assets/fonts/ReadexPro.ttf` — required by the Flutter UI and all PDF exports in P1.24.
- the existing files under `website/public/fonts/` — required by the web app styling that already used them.

If you extract P1.24 into a new folder instead of updating the existing folder, copy those existing font assets from your own prior local Halaqah project into the same paths before running Flutter or the website. No new third-party font file is required by P1.24.

## Recommended Flutter verification

Run in this order after applying the source update:

```powershell
flutter clean
flutter pub get
flutter analyze
flutter test
flutter run
```

Then export at least a student-period PDF and a Quran exam paper to verify Arabic shaping and RTL layout on the target device.

## Supabase

P1.24 Supabase SQL is prepared but is not executed by this package. Run the supplied P1.24 SQL only when you are ready to enable cloud synchronization for the new learning-unit and Quran-course fields, then run the verification SQL and confirm all booleans are `true`.
