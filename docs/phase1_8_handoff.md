# تسليم P1.8 — النسخ الاحتياطي الخلفي وإصلاح التشخيص

التاريخ: 2026-07-19  
الإصدار: `4.2.0-alpha.4+46 (P1.8)`

## ما أُنجز

- إصلاح خطأ البناء الناتج عن `Database.getVersion()` باستخدام `PRAGMA user_version`.
- جدولة نسخة محلية مشفرة كل 24 ساعة عبر Android WorkManager، تبدأ بعد الساعة التي يحددها المستخدم.
- مزامنة المهمة مع التفعيل والتعطيل وتغيير الوقت، مع منع تكرار تسجيل المهمة نفسها.
- إبقاء تنفيذ أول فتح بعد الموعد كمسار احتياطي.
- إظهار آخر تشغيل خلفي وحالته وخطأ الجدولة في الإعدادات ومركز التشخيص.
- اختبار سياسة حساب أول موعد، وفحص عقد مستقل للمرحلة.

## التشغيل على Windows

من جذر المشروع، وليس من مجلد `website`:

```powershell
flutter clean
flutter pub get
flutter run
```

سيضيف `flutter pub get` حزمة `workmanager` إلى ملف القفل المحلي. بعد تشغيل التطبيق مرة واحدة، افتح: الإعدادات ← البيانات، وأعد حفظ وقت النسخ لتأكيد ظهور حالة الجدولة.

## اختبار القبول على جهاز Android

1. اضبط عبارة حماية للنسخ، وفعّل النسخ المحلي التلقائي.
2. اختر الساعة التالية للوقت الحالي، ثم أغلق التطبيق بالطريقة العادية دون «فرض الإيقاف».
3. انتظر وقتًا مناسبًا بعد الموعد؛ Android لا يضمن الدقيقة نفسها.
4. افتح الإعدادات ← البيانات أو التشخيص، وتحقق من حالة آخر تشغيل خلفي ومن زيادة عدد النسخ.
5. أعد التجربة مع وضع توفير البطارية لتوثيق مقدار التأخير على الجهاز.

## قاعدة البيانات

لا يوجد SQL جديد لهذه المرحلة.
