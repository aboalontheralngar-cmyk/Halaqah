# P1.27 Build 76 Hotfix 1 — Flutter compile fixes

**Date:** 2026-08-15  
**Base:** P1.27 Build 76 (`4.3.0-alpha.22+76`)  
**SQLite:** 25 (unchanged)  
**Supabase SQL:** no new SQL

## Why this hotfix exists

The owner's live Build 76 verification showed that Supabase Build 76 SQL was healthy, and dependency resolution completed successfully, but `flutter analyze`, tests, and Android compilation stopped on three source-level regressions introduced in Build 76.

## Fixed

1. **Peer competition group total type**
   - Build 76 computed a memorized range through an untyped `Map`, causing the expression to be inferred as `num` while the accumulator was `int`.
   - The screen now reuses the existing `_ayahCount(...)` int-safe helper.

2. **Peer group dropdown callback syntax**
   - Removed the invalid `void _regroup(value)` statement from the `onChanged` callback.
   - The callback now invokes `_regroup(value)` normally when a value is selected.

3. **Semantic theme import in memorization screen**
   - Added `../../app/theme.dart` so `AppSemanticColors` resolves in the memorization status chips.

## Database status

No database change is required. The owner already ran Build 76 VERIFY and all rows returned `passed=true`.

Do **not** rerun Build 76 APPLY for this hotfix.
