# P1.27 Build 86 Hotfix 11 — UI workflows and responsive hardening

Build 86 is a Flutter-only workflow/UI update. It does not add a Supabase migration or a SQLite schema migration.

## Smart plans

- Adds explicit selection mode to weekly/monthly smart plans.
- Supports select-all for the current filtered list, bulk delete, and one A4 PDF containing the selected plans.
- Adds a separate "print all current plans" action; it no longer requires creating a new batch first.
- Bulk deletion is atomic in SQLite and records the deleted plan ids for cloud sync in one transaction.

## Recitation workspace

- Replaces the three memorization/revision/talaqqin tabs with one student list.
- Physical swipe right opens new memorization; physical swipe left opens revision.
- The three-dot menu contains talaqqin, live recitation session, and memorized-Quran view.
- The obsolete general `MemorizationPlanScreen` route/button is removed; smart plans remain the supported planning workspace.
- Navigation-return reloads are guarded by `mounted` checks to avoid rebuilding disposed screens.

## Responsive fixes

- Hijri day cells are taller and text is scale-down protected, fixing the repeated sub-pixel `BOTTOM OVERFLOW` on compact phones.
- Aggregate halaqah report metric cards get more vertical room and resilient labels, fixing the repeated bottom overflow and hidden labels.
- Home "advanced tools" use the same compact responsive grid as daily actions instead of falling back to one wide tile per row on narrow phones.

## Incident recovery

- Debug builds print privacy-safe incident code/source/type metadata to the Flutter console.
- ErrorWidget now offers a safe back action when a Navigator route is available.
- The recitation/plans/report async return paths touched in this build avoid post-dispose UI work.

## Version

- Flutter: `4.3.0-alpha.29+86`
- SQLite: remains `28`
- Supabase SQL: none
