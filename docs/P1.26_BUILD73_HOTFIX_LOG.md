## Flutter compile recovery

The owner's real `flutter analyze`, `flutter test`, and `flutter run` output exposed seven `const_eval_method_invocation` failures. P1.26 had changed several text colors to `Theme.of(context).colorScheme.onSurfaceVariant` while leaving the surrounding `Text` constructor `const`. Runtime theme lookup is not a constant expression, so Dart correctly rejected compilation.

Build 73 removes `const` from the seven affected text widgets in:

- `reports_screen.dart`
- `student_period_report_screen.dart`
- `message_templates_screen.dart`
- `student_detail_screen.dart` (two locations)
- `vacations_screen.dart` (two locations)

The P1.26 source validator now protects these exact analyzer regressions. The previous build 72 fixes for missing `BehaviorPoint` / `FundTransaction` imports and the invalid undeclared `package:lints` include remain in place.
