## ما لم يمكن تشغيله هنا

### Flutter

لا يوجد Flutter/Dart SDK في بيئة التحرير، لذلك يجب على جهاز المالك إعادة:

```text
flutter analyze

```

خصوصًا لأن Build 76 يضيف SQLite v25 وشاشات/خدمات Dart جديدة.

### بوابات Node التي تحتاج TypeScript

السلسلة تحتوي 61 validator. ثلاثة منها تحتاج حزمة `typescript` عند التشغيل. استُخدمت نسخة TypeScript 5.8.3 المثبتة عالميًا في بيئة التحرير عبر رابط مؤقت داخل `website/node_modules`، فنجحت البوابات الثلاث أيضًا وأصبحت النتيجة **61/61**. أزيل الرابط قبل التغليف، لذلك لم تُشحن `node_modules` داخل الحزمة.
