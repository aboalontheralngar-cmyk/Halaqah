# حالة الميزات المتبقية — محدّثة في P1.25

هذه الوثيقة كانت في الأصل قائمة عمل بعد P1.17.2، وأصبحت قديمة بعد دفعات P1.18–P1.25. المرجع الحالي للتفصيل هو `docs/P1.25_REMAINING_FEATURE_AUDIT.md`.

## الخلاصة الحالية

لا توجد في قائمة المتطلبات الأساسية السابقة ميزة معروفة ومحددة ما زالت «غير منفذة في المصدر» بعد P1.25. البنود التي كانت هنا متبقية ثم أُنجزت تشمل: تكافؤ الصندوق والمزامنة ثنائي الاتجاه، صندوق الويب، تقارير الويب المطبوعة، بوابات الطالب والأسرة، الإشراف متعدد المراكز، تقوية التقارير، التسميع المتصل، التلقين، الدورات القرآنية، وحدات الحفظ والمراجعة المستقلة، وإدارة الاختبارات.

المتبقي الحقيقي ينقسم إلى مجموعتين:

### 1. قبول خارجي

- `flutter analyze`, `flutter test`, وبناء وتشغيل Android على SDK الفعلي.
- تجربة جهازين ومستخدمين ومركزين مع Supabase الحقيقي واختبار RLS.
- تجربة ترقية SQLite من بيانات مستخدم قديمة.
- اختبار QR مطبوع.
- اختبار طابعات A4/A5/80mm.
- اختبار النسخ المشفر والاستعادة على جهاز ثانٍ.
- اختبار PDF العربي بعد P1.25 على الهاتف والطابعة.
- تفعيل Google OAuth وEdge Functions/Secrets في البيئة المستهدفة عند الحاجة.

### 2. توسعات اختيارية

- ربط Google Drive API مباشرة. النسخ الحالي يعمل محليًا ومع Supabase Storage المشفر ويمكن مشاركة الملف إلى Drive عبر نظام التشغيل. الربط المباشر يتطلب OAuth scopes إضافية ومراجعة خصوصية واعتمادية جديدة؛ لذلك لا يعد نقصًا يمنع اكتمال النواة.

## ملاحظة Supabase P1.25

بعد أن أثبتت البيئة الحالية غياب `public.students`، لم يعد مسموحًا افتراض ترتيب migrations القديمة. يستخدم P1.25 مسارًا آمنًا:

1. `P1.25_SUPABASE_PREFLIGHT.sql` — قراءة فقط.
2. إذا كانت النتيجة `READY_...` فقط، يُنفذ migration التوافق P1.25.
3. بعد نجاحه فقط، يُنفذ `P1.25_VERIFY.sql`.
4. إذا كانت النتيجة `STOP_...` يتوقف التنفيذ وترسل نتيجة الفحص كاملة قبل أي تعديل.
