# P1.27 Build 87 Hotfix 12 — Portal + supervision invitations + deliberate recitation gestures

## الهدف

إغلاق المشكلات التي ظهرت بعد Build 86 في واجهة التسميع والبوابة الإلكترونية، مع إبقاء الواجهة مختصرة وعدم التضحية بالتمرير الرأسي أو بعقود Supabase الحالية.

## واجهة التسميع والتلقين

- أزيل الاعتماد على `flutter_slidable` من هذا المسار، واستبدل ببطاقة `DeliberateSwipeActionCard` تستمع إلى حركة المؤشر بصورة سلبية ولا تدخل في منافسة gesture arena مع `ListView`.
- لا يعتمد السحب إلا بعد حركة أفقية واضحة: حد نية 24px ونسبة اتجاه أفقي/رأسي 2.2 ومسافة تنفيذ 104px. لذلك التمرير الرأسي أو القطري الخفيف لا يفتح الحفظ أو المراجعة.
- قائمة النقاط الثلاث تعرض دائمًا: تسجيل الحفظ، تسجيل المراجعة، تسجيل التلقين، جلسة تسميع، عرض المحفوظ، وسجل التسميع. يتم فحص صلاحية الإجراء عند اختياره بدل إخفائه.
- زر عائم موسع باسم «تسجيل سريع» يفتح ثلاثة أوامر: حفظ، مراجعة، تلقين. كل أمر يفتح منتقي طالب قابلًا للبحث ثم ينقل للشاشة المختصة.

## بوابة الطالب وولي الأمر

- المتصفح لم يعد يتصل بـSupabase Edge Function مباشرة. المسار `/api/student-portal` في Next.js يعمل proxy من نفس نطاق الموقع ويزيل CORS كسبب لفشل البوابة.
- proxy يطبق مهلة 15 ثانية، ويرسل `x-forwarded-for` و`user-agent` حتى تظل بصمة rate limiting مفيدة.
- Edge Function يعيد أخطاء قاعدة البيانات كرمز آمن `portal_database_error` مع reference code، ويحتوي action تشخيصي `health`.
- أضيف RPC خدمة فقط `student_portal_runtime_health()`؛ لا يعرض بيانات طالب أو أسرارًا ولا يملك authenticated صلاحية استدعائه مباشرة.
- `tools/deploy_student_portal.ps1` يضبط origin الإنتاجي وpepper جديدًا ثم يعيد نشر Edge Function.

## دعوات الجهة الإشرافية

دوال الدعوات في Build 74 تستخدم `gen_random_bytes()` و`digest()` بينما كان `search_path` فيها `public, pg_temp`. في Supabase قد توجد pgcrypto داخل schema `extensions`. Build 87 يثبت:

`public, extensions, pg_temp`

على دوال إنشاء/قبول دعوة المركز ودعوة عضو الفريق، ويعيد منح EXECUTE لـ`authenticated` ويطلب من PostgREST إعادة تحميل schema cache.

رسالة الويب لم تعد تصنف كل خطأ يحتوي كلمة `function` على أنه غياب `create_supervisor_organization`; خطأ pgcrypto أصبح له تشخيص مستقل.

## المظهر والنقاط

- أضيف Tailwind v4 custom dark variant المرتبط بكلاس `.dark`، بدل إمكانية تطبيق `dark:` بسبب تفضيل نظام التشغيل بينما التطبيق نفسه في الوضع الفاتح.
- بوابة الطالب لها زر فاتح/داكن مستقل يستخدم نفس `darkMode` المحفوظ ويطبق متغيرات التصميم بدل خلفيات بيضاء ثابتة.
- النقاط في الويب تعرض بحد أقصى منزلتين عشريتين، لذلك قيمة مثل `90.86000000000001` تظهر `90.86`.

## قاعدة البيانات والتشغيل

- Flutter: `4.3.0-alpha.30+87`.
- SQLite: لا تغيير، يبقى schema 28.
- SQL مطلوب: `P1.27_BUILD87_HOTFIX12_APPLY.sql` ثم `P1.27_BUILD87_HOTFIX12_VERIFY.sql`.
- بعد SQL يجب إعادة نشر `student-portal` لأن إصلاح proxy وحده لا يحدث Edge Function الموجودة في Supabase.
