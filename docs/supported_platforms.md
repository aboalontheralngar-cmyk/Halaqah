# منصات الإصدار المدعومة

اعتبارًا من P1.26 Build 74، أهداف الإنتاج الرسمية لمشروع حلقتي هي:

- **Android** — تطبيق Flutter الرئيسي.
- **Web** — واجهة Next.js.

مجلدات `ios/`, `macos/`, `linux/`, و`windows/` هي Flutter scaffolding محفوظة لإمكان التوسع لاحقًا، وليست أهداف Release معتمدة حاليًا. لذلك قد تحتوي معرفات `com.example` الافتراضية، ولا يجوز نشرها كما هي.

أي تفعيل إنتاجي لمنصة جديدة يتطلب تحديد bundle/application ID رسمي، إعداد التوقيع، مراجعة صلاحيات النظام، اختبار التخزين الآمن، QR/كاميرا، المشاركة والطباعة، ثم إضافتها صراحة إلى CI وقائمة الإصدار. لا يُفترض معرف إنتاجي نيابةً عن المالك.
