# تسليم الإصلاح P1.17.2 — مركز الإعدادات المنظم

> **تنبيه تحديث (Build 78 Hotfix 3):** هذه وثيقة تسليم تاريخية لـP1.17.2 وليست قائمة المتبقي الحالية. راجع `docs/INDEX.md` و`docs/P1.27_REMAINING_PLAN.md` قبل اتخاذ قرار تنفيذي.

الإصدار: `4.3.0-alpha.9+59 (P1.17.2)`  
التاريخ: 2026-07-22

## النتيجة

- تظهر إعدادات المعلم اليومية منفصلة عن الإدارة والحماية.
- يمكن البحث بكلمات مثل النسخ والمزامنة والأوقات والتشخيص للوصول إلى القسم المناسب.
- قسم البيانات لا يعرض كل العمليات الحساسة معًا؛ بل يتنقل بين النسخ والحماية، والمزامنة والاتصال، والخصوصية والسجل.
- مركز إدارة النظام يوضح متى يستخدم مدير النظام الجاهزية أو التشخيص الفني أو سجل التدقيق.
- لم تتغير عقود النسخ أو المزامنة أو قاعدة البيانات؛ التعديل تنظيمي ومرئي.

## الميزات المتبقية فعليًا

1. تكافؤ تقرير الطالب الإداري في الويب مع PDF المحمول كامل التفاصيل.
2. تنزيل معاملات الصندوق والنقاط إلى الأجهزة الأخرى، واستكمال تسوية المخالفات في صندوق الويب.
3. تنزيل التقارير والخطط التاريخية وإدارة تنبيهات ولي الأمر داخل البوابة.
4. اعتماد الجهة الإشرافية ومقارنات المراكز وسجلها الإداري الموسع.
5. تكامل Google Drive الاختياري؛ النسخ الحالي يستخدم Supabase Storage المشفر.
6. إعادة تركيب ما تبقى من الشاشات الإدارية القديمة بصريًا، ثم مراجعة جهازين.
7. واجهة إدارية لإصدارات قواعد النقاط وشرائح المراجعة دون تغيير النتائج القديمة.

## قبول خارجي قبل الإنتاج

- `flutter analyze` و`flutter test` وبناء APK.
- اختبار ترقية SQLite من نسخة بيانات فعلية.
- QR مطبوع على هاتفين، والطباعة A4/A5 والكاشير.
- مزامنة جهازين، واستعادة نسخة مشفرة، واختبار عزل حسابين/عائلتين/مركزين.
- نشر Edge Function للبوابة واختبار حد المحاولات والجلسات.
