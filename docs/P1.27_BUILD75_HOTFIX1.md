# P1.27 Build 75 Hotfix 1 — Flutter dependency compatibility

**Date:** 2026-08-12  
**Scope:** Flutter dependency resolution only  
**Database:** no schema change

## Symptom

On a current Flutter SDK, `flutter pub get` can stop with:

```text
Because every version of flutter_test from sdk depends on path 1.9.1
and halaqah_teacher depends on path 1.8.3, flutter_test from sdk is forbidden.
```

## Root cause

Build 75 kept an exact direct dependency on `path: 1.8.3`. The Flutter SDK used by the owner pins `path` to `1.9.1` through `flutter_test`, so Pub cannot select one version satisfying both exact requirements.

## Fix

`pubspec.yaml` now uses:

```yaml
path: 1.9.1
```

No application code or SQLite schema is changed. After replacing the file, run:

```powershell
flutter clean
flutter pub get
flutter analyze
flutter test
```

`flutter pub get` should create/update `pubspec.lock` on the owner's machine. Keep that lock file with the application source after the successful solve.
