> **Superseded for installation by Hotfix 3:** Hotfix 2 correctly fixed the Flutter source/API compile blockers, but its `printing 5.14.3` + `share_plus 9.0.0` dependency pair cannot resolve. Install Hotfix 3, which includes all Hotfix 2 fixes plus the dependency-pair correction.

## Owner acceptance already completed

`P1.27_BUILD75_VERIFY.sql` was run successfully on the live Supabase project and every reported check returned `passed = true`. The database migration is therefore not the cause of the current application build failure.

## Runtime evidence received

After Hotfix 1, `flutter pub get` succeeded but reported `Changed 41 dependencies!` and downgraded several direct packages that had previously been present in the owner's lock file. The resulting `flutter analyze`, `flutter test`, and `flutter run` exposed five compile blockers:

1. `supabase_flutter 2.8.2` does not accept `publishableKey:` in `Supabase.initialize`.
2. `showDatePicker` does not have a `saveText:` argument; it uses `confirmText:`.
3. `FontWeight.black` is not a Flutter constant; the black weight is `FontWeight.w900`.
4. `printing 5.11.1` uses an old Flutter `ViewConfiguration` API and fails against the owner's current Flutter SDK.
5. Minor analyzer findings: an unused `intl` import, deprecated `DropdownButtonFormField.value`, and parameter names shadowing the `num` type.

## Root cause

Build 75/Hotfix 1 fixed the `path` conflict but still pinned a group of direct dependencies to older exact versions. Because the project lock file had been generated from newer package versions, the next `flutter pub get` legitimately downgraded those packages to the older exact pins. Application code written for the newer APIs then no longer matched the resolved packages.

## Fixes

### Dependency pins

The project now pins the owner's previously resolved direct versions where appropriate, while keeping exact-version reproducibility:

- `cupertino_icons: 1.0.9`
- `sqflite: 2.4.2+1`
- `path: 1.9.1`
- `path_provider: 2.1.5`
- `pdf: 3.12.0`
- `printing: 5.14.3` (selected instead of the older 5.13.1 because it includes newer Flutter AssetManifest compatibility while retaining Dart 3.3 support)
- `shared_preferences: 2.5.5`
- `uuid: 4.5.3`
- `crypto: 3.0.7`
- `image_picker: 1.2.2`
- `supabase_flutter: 2.14.2`
- `flutter_contacts: 1.1.9+2`

The project Dart lower bound is now `>=3.3.0 <4.0.0`, matching the minimum required by the restored modern dependency set.

### Source fixes

- Replaced the three invalid `saveText: 'اعتماد'` arguments on `showDatePicker` with `confirmText: 'اعتماد'`.
- Replaced `FontWeight.black` with `FontWeight.w900`.
- Kept `publishableKey:` and restored `supabase_flutter 2.14.2`, which supports that API.
- Replaced the deprecated monthly-plan dropdown `value:` with `initialValue:`.
- Removed the unused `intl` import from `plans_screen.dart`.
- Renamed two callback variables from `num` to `ayahNumber`.
