# تسليم P1.10 — تثبيت الويب والنسخة المرشحة

التاريخ: 2026-07-20  
الإصدار: `4.2.0-alpha.6+48 (P1.10)`

## ما أُنجز

- إغلاق ملاحظات ESLint الـ23 وتشديد `lint:ci` إلى صفر تحذيرات.
- تثبيت اعتمادات React في الحضور والتقارير والحفظ والمراكز والمعلمين والتنقل.
- إزالة تحديثات الحالة المتزامنة داخل تأثيرات لوحة التحكم والقرعة والعائلات والقوالب وخريطة المصحف.
- إضافة فحص عقد P1.10، فأصبح مجموع بوابات المصدر 35.
- مراجعة وضع جداول بوابة الطالب والعائلة وتأكيد أن `RLS=true` و`policies=0` وضع إغلاق مباشر مقصود.

## Supabase

لا يوجد SQL جديد لهذه المرحلة. لا تنشئ سياسات وصول مباشر لجداول
`credentials/sessions/login_attempts`. شغّل فحص الجاهزية للقراءة فقط، ويجب أن
تظهر هذه الجداول في مجموعة `deny-all` بقيمة `passed=true`.
