# P1.24 — SQL and rollout instructions

## Important

The P1.24 Supabase migration is prepared but **not executed**. Local SQLite upgrades automatically to schema 23 when the Flutter app opens.

## When you are ready to enable cloud sync for P1.24

1. Take a Supabase backup / confirm a restorable database snapshot.
2. Open Supabase SQL Editor.
3. Copy the complete contents of:
   `website/supabase/migrations/20260808000200_p1_24_courses_learning_units.sql`
4. Run the whole migration once.
5. Run `website/supabase/verify_p1_24.sql` (also supplied separately as `P1.24_VERIFY.sql`).
6. Confirm every returned boolean is `true`.
7. Then test two-device sync for:
   - independent review unit;
   - Talaqqin stage flag;
   - Quran courses;
   - course enrollment changes and deletion.

Before the migration is applied, these features continue to work locally. Cloud sync catches missing-table/missing-column errors for the new schema and does not treat them as permission to discard the local records.

## No destructive table operations

The migration contains no `DROP TABLE` and no `TRUNCATE`. It uses `ADD COLUMN IF NOT EXISTS`, `CREATE TABLE IF NOT EXISTS`, scoped constraints/policies/triggers, and backfills existing rows.
