## Owner-device failure reproduced from log

The previous build reached Dart analysis/compilation and failed because `lib/services/supabase_service.dart` instantiated `BehaviorPoint` and `FundTransaction` while their model imports were missing. The same compile failure propagated into `flutter test` and `flutter run`.

The analyzer also reported an unresolved `package:lints/recommended.yaml` include plus dead report imports/helpers.

## Fixes

1. Restored `../models/behavior_point.dart` in `supabase_service.dart`.
2. Restored `../models/fund_transaction.dart` in `supabase_service.dart`.
3. Removed the unresolved external `package:lints/recommended.yaml` include from `analysis_options.yaml`; no new package dependency is introduced by this hotfix.
4. Removed the dead legacy report imports/helpers reported by the owner's analyzer. The active WhatsApp period-report implementation remains in `student_period_report_screen.dart`, including day names and daily detail.
5. Updated the P1.24 regression contract to protect the active WhatsApp report path rather than an unused legacy helper.
6. Updated release validators to build 72 and added regression checks requiring both Supabase model imports.
